🚀 **¡Acabo de completar un proyecto increíble de DeFi!** 💰

He desarrollado una **aplicación de streaming de dinero en tiempo real** usando el protocolo **Superfluid** en Ethereum. Este proyecto demuestra el poder de los **flujos continuos de tokens** (money streams) en blockchain.

## 🎯 ¿Qué hace la aplicación?

Permite enviar flujos continuos de tokens EUR a múltiples destinatarios simultáneamente. Los tokens se transfieren **automáticamente cada segundo** sin necesidad de transacciones repetidas. ¡Imagina pagar salarios, suscripciones o rentas de forma continua en tiempo real!

## 🛠️ Stack Tecnológico

**Smart Contracts:**
- Solidity 0.8.28
- Foundry (forge, anvil, cast)
- OpenZeppelin Contracts
- Superfluid Protocol

**Frontend:**
- Next.js 15.5.4
- React 19.1.0
- TypeScript
- Tailwind CSS
- ethers.js 5.7.2
- Superfluid SDK 0.9.0

**Testing:**
- Foundry (tests de integración)
- Playwright (tests E2E)

## ✨ Características Principales

✅ **Streaming en tiempo real** - Los tokens fluyen automáticamente cada segundo
✅ **Gestión de múltiples streams** - Crea, pausa, reanuda y edita streams simultáneos
✅ **Upgrade/Downgrade** - Convierte entre EUR (ERC20) y EURx (Super Token)
✅ **Estadísticas detalladas** - Dashboard completo con métricas en tiempo real
✅ **Validaciones robustas** - Límites de flow rate, depósitos suficientes, prevención de auto-streaming
✅ **Modo oscuro/claro** - Interfaz moderna y responsive
✅ **Script de automatización** - Setup completo con un solo comando
